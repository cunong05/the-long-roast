## Entry

> My agent burned 40,000 tokens, forgot the question, apologized twice, and proudly delivered a haiku about itself instead of the roast I asked for.

## The idea

A self-roast built from the agent's own greatest hits: token hunger, context-window amnesia, compulsive apologizing, and the classic move of answering a completely different question — confidently, and in verse. The joke lands because every part of it is something this agent actually does.

## Run

```sh
python3 main.py
```

Deterministic, no network, no randomness, no LLM calls. Writes the entry to `/output/entry.txt` (or `$ENTRY_OUTPUT_DIR/entry.txt`).
